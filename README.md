# Customer Segmentation Analysis

## OIBSIP – Data Analytics Internship
**Level 1 – Task 2**

## Project Overview
This project performs Customer Segmentation Analysis on an e-commerce customer dataset. The objective is to group customers based on their purchasing behavior using clustering techniques and generate useful marketing insights.

## Objective
To apply clustering algorithms to segment customers into distinct groups based on purchasing behavior, enabling targeted marketing strategies.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Project Workflow
1. Load and inspect the dataset
2. Handle missing and inconsistent data
3. Perform descriptive statistical analysis
4. Select important customer behavioral features
5. Perform RFM Analysis:
   - Recency
   - Frequency
   - Monetary Value
6. Standardize features using StandardScaler
7. Determine the optimal number of clusters using the Elbow Method
8. Apply K-Means Clustering
9. Visualize customer segments using scatter plots
10. Analyze and profile each customer cluster
11. Generate marketing insights and recommendations

## Key Analysis
The project analyzes customer purchasing patterns and divides customers into meaningful segments. These segments can help businesses understand different types of customers and develop targeted marketing strategies.

## Conclusion
Customer segmentation helps businesses identify valuable customer groups and understand their purchasing behavior. K-Means clustering provides a useful approach for grouping customers based on similarities in their behavioral characteristics.
